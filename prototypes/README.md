# Prototypes visuels

Trois directions pour le site de Thed, à tester sur téléphone. Détail dans [doc/06](../doc/06-directions-visuelles.md).

| Fichier | Direction | Tech |
| --- | --- | --- |
| `01-le-vol.html` | Du sol aux étoiles, planeur 3D | Three.js 0.149 (CDN) |
| `02-carnet-de-vol.html` | Cahier d'écolier, marqueur, mini-jeu (**abandonné**) | HTML/CSS/JS, sans librairie |
| `03-embarquement.html` | Nuit, intro vidéo, avion en papier, lecteur de l'EP, dates à palettes (V3) | HTML/CSS/JS, sans librairie |
| `04-merch-simple.html` | **Base retenue (26/11).** « Thed · Merch » : boutique fond blanc, header nuit, vidéo, live, concerts Bandsintown ([doc/07](../doc/07-base-merch.md)) | HTML/CSS/JS, sans librairie |

- Assets : `assets/`, issus du Drive « visuels » (images redimensionnées, vidéos coupées et compressées sans son).
- Audio : `assets/ep-demo.mp3` = son de la live session (démo). À remplacer par les 6 titres de l'EP.
- Prix et dates de concert fictifs.
- Les fichiers sont des fragments HTML (pas de `<html>`/`<head>`), publiés comme Artifacts claude.ai. Ils s'ouvrent aussi tels quels dans un navigateur.
